Network Traffic Analysis

Project Status: In Progress

1. Overview

This project explores the fundamentals of computer networking and network traffic analysis.

It focuses on understanding how devices communicate, how data travels across networks, and how different network protocols support communication.

2. Objectives

* Understand basic networking concepts.
* Explore IP addressing and ports.
* Understand TCP and UDP protocols.
* Examine the role of DNS and HTTP/HTTPS.
* Learn how to capture and analyse network packets using Wireshark.

3. Tools
